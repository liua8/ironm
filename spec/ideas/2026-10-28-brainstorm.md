# 头脑风暴整理（2026-10-28）

项目负责人的头脑风暴，按"解决什么问题"分成 6 类；每条注明和 iron-m 现状的关系，最后给出先后建议。这里只是想法池，不是需求；要做的条目再按惯例写进 `spec/spec.md` 和 `spec/testing.md`。

## 一、Agent 底层能力：让回答更准、更连贯

| 想法 | 理解 | 现状 |
|---|---|---|
| Skill 按关键词装载不行 | 由模型看上下文决定装哪个 Skill，关键词只用来兜底 | 现在是模型、关键词、向量三路打分；10-28 已定"由模型判断" |
| 连贯性和可溯源性 | 前后说法一致；每个结论都能查到依据、数据和时间 | 有出处核对（回答里不展示）；今日状态每条带时间 |
| 语义怎么统一 | 同一件事各处叫法一致，如"感受分 / RPE""轻松版 / 减量" | 没有统一词表 |
| 偏好生成、经验沉淀 | 从打卡和选择里总结习惯偏好；好的做法沉淀成 Skill | 已能从训练记录总结偏好；沉淀成 Skill 即进化环 |
| Agent 记忆做成可复用资产 | 把练出效果的"进度方案"存成模板，给相似的人用 | 没有 |
| 给体态一致的人提供建议 | 按身高、体重、体脂、目标相近的人群给参考 | 没有，需要人群数据 |
| 博主语气做成 Skill（赛博教练） | 可选教练风格：严厉、鼓励、某种博主风格 | 没有 |

## 二、训练计划与执行

| 想法 | 理解 | 现状 |
|---|---|---|
| 根据指标数据及时调整 | 状态、恢复、进度没到预期时调整计划 | 部分有：今天的版本、加减重量、复盘；缺"预期"和阶段评估 |
| 计划临时调整、可执行性 | 今天临时没空、没器械，当场改今天的安排 | 有"只有 30 分钟""有点累"、天气调整 |
| 训练中实时调整 | 练到一半太累或太轻，当场改后面几组 | 没有 |
| 动作适配程度判断 | 这个动作适不适合你：伤病、器械、水平 | 有替代动作和计划检查，没有"适配度" |
| 一键应用到我的计划 | 看到别人的方案或建议，一键套到自己的计划 | 改计划先出预览、确认后生效；没有"从外部方案导入" |
| 平台自己生成训练动作？ | 动作是否由 AI 自创 | 建议不做：动作要有出处，安全上不能编；只从动作库挑选和组合 |
| 打卡细化 | 逐组打卡或一键打卡；可选记重量的方式；可计时 | 有每组记录；没有计时和多种记录方式 |
| 视频识别动作规范、动作指导 | 拍视频判断动作对不对 | 没有；技术难度高，误判有安全风险 |
| 如何完整打造一个训练计划 | 排计划的流程、参考依据、怎么评测（评测先行） | 有依据库和计划检查；可整理成方法论，作为 Skill 和评测标准 |

## 五、"从夯到拉"排行榜（一个系列）

- 适合做成社区内容和互动，用户投票。
- 补充剂排行涉及健康声明，要谨慎：只说成分和证据等级。

## 先后建议

1. **先做**（和现在的 Agent 主线一致）：Skill 由模型判断装载；连贯性和可溯源（统一词表、今日状态、预期）；根据指标调整；计划临时调整；打卡细化（逐组 / 一键、计时）。
2. **其次**（计划和饮食更实用）：训练中实时调整；动作适配度；一键应用到计划；菜谱；经验沉淀成 Skill；进度方案模板化。
3. **再往后**（需要用户量或新数据）：社区；排行榜；相似体态推荐；附近点餐；教练风格；小宠物。
4. **不做或暂缓**：平台自创动作（安全和出处）；视频识别动作（成本高、误判风险大，App 阶段再评估）。
