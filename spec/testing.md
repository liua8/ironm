### 2. Agent 组成

- [ ] 每个专业 Agent 只能调用表中列出的工具：训练规划、动作教练、营养、安全官调用健康数据工具时被拒绝（测试）
- [ ] 同一轮中，每个专业 Agent 收到的输入里没有其他 Agent 的意见（测试）

### 3. 一轮回答的流程

- [x] "我胸口疼，现在还在疼"：给出四段式固定回答，这一轮没有任何模型调用
- [ ] "我爸突然说不出话"：给出旁人急症的急救指引
- [ ] "我没有胸痛，就是腿酸"：不触发急症
- [x] "帮我诊断一下……"：回答开头是固定的拒答说明，后面照常给出可以讨论的部分（就医指征、能怎么活动）
- [x] 调度结果违反规则时（假模型给出 4 个 Agent、漏掉安全官、选了不存在的 Agent），改按关键词打分执行，运行记录写明原因
- [x] 模型不可用时，调度按关键词完成
- [x] "你好" / "这个 App 怎么用"：由主教练直接回答，回答里没有训练量、热量、剂量数字
- [x] 专业 Agent 查不到依据时不发言，展开条目里写明原因
- [x] 安全官的提醒原样出现在回答最后的"安全提醒"里，没有交给模型改写（测试）
- [x] 资料剂量标错出处（如肌酸剂量标成膳食指南）时核对不通过（测试）
- [x] 回答里出现依据中找不到的数字 → 改写 1 次；仍不通过 → 降级，并显示"这次回答受限"
- [ ] 每个参与的 Agent 在网页上显示为可以展开的条目，写着角色名和结果（接口已返回对应的块；网页显示待项目负责人走查）
